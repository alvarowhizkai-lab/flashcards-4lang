# 四国语言背单词App

🇨🇳🇬🇧🇪🇸🇧🇷 科技/电动车/外贸 词汇学习

## 快速开始

### 方法1：直接打开（推荐）
双击打开 `index.html` 文件即可使用！

### 方法2：使用本地服务器（更稳定）
```bash
# 进入目录
cd ~/Desktop/ABC

# 启动服务器
python3 -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

## 功能

- ✅ 卡片式学习，点击翻转显示翻译
- ✅ 四国语言对照（中/英/西/葡）
- ✅ 包含例句，帮助理解
- ✅ 标记认识/不认识，跟踪学习进度
- ✅ 分类筛选（科技/电动车/外贸）
- ✅ 随机打乱顺序
- ✅ 葡语重点模式（初学者友好）
- ✅ 键盘快捷键支持

## 键盘快捷键

| 按键 | 功能 |
|------|------|
| 空格/回车 | 翻转卡片 |
| → 右箭头 | 认识（下一张） |
| ← 左箭头 | 不认识（再学一次） |
| S | 随机打乱 |

## 词汇数据

- 科技类：15词
- 电动车：15词  
- 国际贸易：15词
- 共计：45词（示例版，可扩展）

## 添加更多词汇

编辑 `data/vocabulary.json` 文件，按相同格式添加新词汇：

```json
{
  "id": 数字,
  "category": "tech|ev|trade",
  "chinese": "中文",
  "english": "英文",
  "spanish": "西班牙语",
  "portuguese": "葡萄牙语",
  "example_cn": "中文例句",
  "example_en": "英文例句",
  "example_es": "西班牙语例句",
  "example_pt": "葡萄牙语例句"
}
```
